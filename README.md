# 🔔 Strelo — Напоминалка для Windows (C# WinForms)

Полнофункциональная десктопная программа-напоминалка для Windows 10 / 11 на **C# (Windows Forms)** с выводом всплывающего окна поверх всех окон, звуковым оповещением, функцией «Отложить» (Snooze), повторами, автосохранением и работой в системном трее.

---

## ✨ Возможности

- **Всплывающее окно поверх всех окон (`TopMost`)**:
  - Гарантированно появляется поверх открытых программ и мигает в панели задач.
  - Выделяется цветом в зависимости от приоритета (синяя шапка для обычных, красная — для важных напоминаний).
  - Кнопки **«Отложить»** на `+30 сек`, `+5 мин`, `+15 мин`, `+1 час`, `+1 день` или на любое своё значение в **секундах, минутах, часах, днях, месяцах или годах**.
  - Кнопка **«Понятно (Выполнено)»** — завершает разовое напоминание или автоматически переносит повторяющееся напоминание на следующий цикл.
- **Два удобных способа задания времени**:
  - **Через сколько (таймер по 6 единицам)** — точный выбор смещения: **Годы, Месяцы, Дни, Часы, Минуты и Секунды** (плюс быстрые кнопки `30 сек`, `5 мин`, `15 мин`, `1 час`, `1 день`, `1 мес`, `1 год`, `Сброс` и живой предпросмотр точного времени срабатывания).
  - **В точное время и дату** — выбор календарной даты и времени с точностью до секунды (плюс быстрые кнопки «Сегодня в 18:00», «Завтра в 09:00»).
- **Гибкие повторы**:
  - Один раз (без повтора)
  - Каждые `N` минут (интервальный таймер)
  - Ежедневно
  - По будням (Пн–Пт)
  - Еженедельно
- **Живой список напоминаний**:
  - Отображает статус, текст, точное время срабатывания и **живой обратный отсчёт** до срабатывания.
  - Поддерживает редактирование, паузу/возобновление, откладывание и удаление.
- **Системный трей (возле часов)**:
  - При нажатии на крестик программа не закрывается, а сворачивается в системный трей и продолжает следить за временем в фоне.
  - Из контекстного меню иконки в трее можно в 1 клик создать быстрое напоминание на 5, 15 или 30 минут, включить режим **«Не беспокоить»** или полностью выйти из программы.
- **Автосохранение и автозапуск**:
  - Все напоминания автоматически сохраняются в `%APPDATA%\StreloReminder\reminders.json` и восстанавливаются после перезапуска ПК.
  - Опция **«Автозапуск с Windows»** прямо в шапке окна.

## 🚀 Как получить или собрать `StreloReminder.exe` на Windows

### Способ 0. Скачать готовый `.exe` из GitHub Actions (без сборки на ПК)

При каждом изменении в репозитории автоматически запускается пайплайн **GitHub Actions (`Windows Build & Artifacts`)**, который компилирует программу на сервере GitHub и прикрепляет готовые файлы к сборке:
1. Перейдите во вкладку **Actions** → выберите последний успешный запуск **Windows Build & Artifacts**.
2. В блоке **Artifacts** внизу страницы скачайте:
   - **`StreloReminder-Standalone-Win10-11`** — полностью автономный `StreloReminder.exe` (~30 КБ), работающий на любой Windows 10 / 11 без установки дополнительного ПО.
   - **`StreloReminder-Net8-WinX64`** — сборка под .NET 8 (`win-x64`).

### Способ 1. Локальная сборка в один клик без установки Visual Studio и SDK

На каждом компьютере с Windows 10 / 11 уже встроен системный компилятор C# (`csc.exe`).

1. Скачайте или клонируйте репозиторий.
2. Дважды нажмите на файл **`build.bat`**.
3. Скрипт за 1 секунду соберёт **`StreloReminder.exe`** в папке проекта и сразу запустит программу!

### Способ 2. Через .NET SDK или Visual Studio

Если у вас установлен **.NET 8 SDK** или **Visual Studio 2022**:

```cmd
dotnet run
```

Или для сборки в готовый `.exe`:

```cmd
dotnet build -c Release
```

Также вы можете открыть файл решения **`StreloReminder.sln`** в Visual Studio и нажать **F5**.

## 📂 Структура проекта и документация для агентов

```text
StreloReminder/
├── .github/workflows/build.yml     # Автосборка проекта на Windows в GitHub Actions
├── Program.cs                      # Точка входа + защита от повторного запуска (Mutex)
├── Forms/
│   ├── MainForm.cs                 # Главное окно программы, таблица, таймер и системный трей
│   └── PopupNotificationForm.cs    # Всплывающее окно поверх всех окон (TopMost + Snooze)
├── Models/
│   └── ReminderItem.cs             # Модель напоминания, расчёт повторов и обратного отсчёта
├── Services/
│   ├── StorageService.cs           # Сохранение/загрузка JSON и управление автозапуском в реестре
│   └── IconGenerator.cs            # Программная генерация иконки колокольчика для окна и трея
├── StreloReminder.csproj           # Файл проекта .NET 8 (WinForms)
├── StreloReminder.sln              # Решение для Visual Studio
├── build.bat                       # Скрипт быстрой сборки в StreloReminder.exe в один клик
├── AGENTS.md                       # Техническая документация и регламент для ИИ-агентов
└── CHANGELOG.md                    # Подробный пошаговый журнал всех изменений
```

> **Для ИИ-агентов и контрибьюторов**: перед внесением любых правок ознакомьтесь с [`AGENTS.md`](AGENTS.md). Каждое изменение обязательно фиксируется в [`CHANGELOG.md`](CHANGELOG.md) и проверяется автосборкой в GitHub Actions.
